# Shell, I/O Redirections and Filters

0-hello_world: Prints "Hello, World" followed by a newline.
1-confused_smiley: Prints the confused smiley.
2-hellofile: Displays the contents of /etc/passwd.
3-twofiles: Displays the contents of /etc/passwd and /etc/hosts.
4-lastlines: Displays the last 10 lines of /etc/passwd.
5-firstlines: Displays the first 10 lines of /etc/passwd.
6-third_line: Displays the third line of iacta.
7-file: Creates a file named \*\\'"Best School"\'\\*$\?\*\*\*\*\*:)
8-cwd_state: Writes the current directory listing to ls_cwd_content.
9-duplicate_last_line: Appends the last line of iacta to the file.
10-no_more_js: Deletes all .js files in the current directory and its subdirectories.
11-directories: Counts directories and subdirectories, excluding the current directory.
12-newest_files: Displays the 10 newest files, one per line.
13-unique: Sorts input words and displays only those occurring exactly once.
14-findthatword: Displays lines containing "root" from /etc/passwd.
15-countthatword: Counts lines containing "bin" in /etc/passwd.i
16-whatsnext: Displays lines containing "root" and the 3 following lines from /etc/passwd.
17-hidethisword: Displays lines from /etc/passwd that do not contain "bin".
18-letteronly: Displays lines from /etc/ssh/sshd_config that begin with a letter.
19-AZ: Replaces A with Z and c with e from standard input.
20-hiago: Removes all lowercase c and uppercase C characters from input.
21-reverse: Reverses the characters in each line of input.
22-users_and_homes: Displays usernames and home directories from /etc/passwd, sorted alphabetically.
